# Aba Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Abas Builds | Kit | Rotação na tela do personagem; Kit com o kit oficial em PT-BR (Aemeath, Yangyang, Suoming nesta entrega).

**Architecture:** Um script importa o kit das tabelas do jogo (Arikatsu, textmap PT) para `data/kits.json`, já com o texto convertido em parágrafos de trechos estilizados, e baixa as imagens do nanoka para `data/imagens/kit/`. A API serve kit + resumo (`data/kit_resumos.json`, escrito à mão) e as imagens. A página desenha só com nós de texto.

**Tech Stack:** Python 3.13, Pydantic 2, FastAPI, pytest (`uv run pytest`), Pillow; JS vanilla (módulos ES) em `web/`.

**Spec:** `docs/superpowers/specs/2026-11-01-aba-kit-design.md`

## Global Constraints

- Texto do kit = texto oficial do jogo em PT (`Textmaps/pt/multi_text/MultiText.json`); sem PT → texto oficial EN + aviso. Nada inventado.
- Fonte = mesmo repositório/commit de `data/fonte_dados_jogo.json` (`Arikatsu/WutheringWaves_Data`, `9218d612…`), salvo `--ref`.
- Imagens: `/Game/Aki/UI/<resto>.<nome>` → `https://static.nanoka.cc/assets/ww/<resto>.webp` (reusar `url_do_icone`). Barra do forte: `forte.icon` de `https://static.nanoka.cc/ww/{versao}/en/character/{id}.json`, `versao` padrão `"3.8.1"`.
- Sem `innerHTML` com texto de dados; só `el(...)`/nós de texto.
- Ordem oficial: ATQ Normal (tipo 1), Habilidade de Ressonância (2), Circuito Ressonante (6), Liberação (3), Intro (5), Outro (11); depois Inerentes (4, 7, 8, 9, 10, pela ordem do nó) e Ruptura de Sintonia (12); depois S1–S6.
- Multiplicadores: níveis 1–10 (`ArrayString[:10]`). Seletor começa no 10.
- Erros com contexto, sem "failed to"; `catch {}` vazio proibido; type hints em tudo; testes colocados ao lado do código, nomes em 3ª pessoa.
- Commits: `feat: ...` / `chore: ...` em minúsculas, ≤72 chars, sem "Claude Code".

## Review Focus

1. Personagem sem kit importado (ex.: Shorekeeper) → API 404 e aba Kit mostra "Kit ainda não importado", sem quebrar Builds. Teste na Task 4 e verificação na Task 5.
2. Chave com `:` e espaço (`Yangyang: Xuanling`) → URL com `encodeURIComponent`, arquivo de imagem via `nome_de_arquivo`. Teste na Task 2.
3. `?aba=` com valor desconhecido → cai em Builds. Verificação na Task 5.
4. Habilidade sem multiplicadores (Inerente, Outro) → sem tabela e sem seletor. Teste na Task 3 e verificação na Task 5.
5. Imagem que não baixou → placeholder, e o import continua. Teste na Task 3.

### Task 1: Conversor do texto do jogo

**Files:**
- Create: `src/wuwastats/gamedata/kit_texto.py`
- Test: `src/wuwastats/gamedata/test_kit_texto.py`

**Interfaces:**
- Produces:
  - `Estilo = Literal["normal", "subtitulo", "destaque", "aero", "fusion", "electro", "glacio", "havoc", "spectro"]`
  - `class Trecho(BaseModel)`, frozen, extra forbid: `texto: str`, `estilo: Estilo`
  - `Paragrafo = list[Trecho]`
  - `converter_texto(texto: str, parametros: Sequence[str]) -> tuple[list[Paragrafo], list[str]]`, que devolve parágrafos e avisos.

Regras:
- primeiro `{n}` → `parametros[n]` (índice sem parâmetro fica como está; reaproveite a lógica de `preencher` movendo-a para cá e importando no script antigo);
- `{Cus:Ipt,Touch=… PC=<x> Gamepad=…}` → `<x>`, que vai até o próximo ` Gamepad=` ou `}`;
- `<color=Title>` → `subtitulo`;
- `<color=Highlight>` e `<te href=N>` → `destaque`;
- `<color=Wind|Fire|Thunder|Ice|Dark|Light>` → `aero|fusion|electro|glacio|havoc|spectro`;
- `<size=…>` não muda o estilo;
- um `<size=10>` só com espaço, ou uma linha vazia, separa parágrafos;
- cada `\n` fecha o parágrafo;
- trechos vizinhos de mesmo estilo se juntam;
- trechos só com espaço somem;
- tag desconhecida → mantém o texto de dentro com o estilo atual e gera o aviso `"marcação desconhecida: <tag>"`.

**Interfaces:**

    - `MultiplicadorFonte`: `SkillLevelGroupId`, `AttributeName`, `Description`, `Order`, `SkillDetailNum`
    - `SequenciaFonte`: `GroupId`, `GroupIndex`, `NodeName`, `AttributesDescription`, `AttributesDescriptionParams`, `NodeIcon`
    - `TagFonte`: `Id`, `TagName`, `TagDesc`, `TagNameColor`
    - `TipoFonte`: `Id`, `TypeName`

  - `@dataclass(frozen=True) ImagemKit(nome: str, url: str)`.

Nomes de imagem:
- `"habilidade-<NodeIndex>"`;
- `"sequencia-<n>"`;
- `"forte"`.

Regras:
- `Kit.habilidades[i].imagem` guarda o **nome** da imagem, não a URL;
- `None` quando `url_do_icone` recusa o caminho;
- multiplicador com `Description` não vazio formata cada valor com `preencher(texto(Description), [valor])` (ex. `"16s"`);
- texto: PT, senão EN + aviso `"<chave> sem PT"`;
- bônus somados por `PropertyNodeTitle` (sem o `+` final), valores em `%` somados com 2 casas e zeros à direita tirados (`"12%"`, `"8%"`);
- nome da chave = nome EN do personagem, igual a `resonators.json`.

- As imagens que faltam são baixadas com `ThreadPoolExecutor(8)`; uma falha vira aviso e o import segue.
- Um personagem com estrutura quebrada (nó sem habilidade) vira aviso e fica de fora; os outros seguem.
